# Architecture Decision Records

Esta pasta registra decisoes arquiteturais duraveis. Um ADR explica o contexto, a decisao, alternativas e consequencias; nao substitui codigo, testes ou o changelog.

## Status

- Proposto: em discussao, sem implementacao.
- Aceito: decisao aprovada para a proxima etapa.
- Implementado: decisao refletida no codigo e validada.
- Substituido: uma decisao posterior tomou seu lugar.

## Convencoes

- Nome: `NNNN-titulo-curto.md`.
- Criar ADR antes de alterar contratos publicos, arquitetura, seguranca, dados, estrategia de IA ou integracao MCP.
- Atualizar `docs/ai-change-history.md` quando a decisao afetar IA.
- Nao alterar ADR historico; criar um novo ADR para substitui-lo.
